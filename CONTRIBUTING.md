# Contributing

Contribute concrete editing cases, architecture analysis, or focused reference examples.
English and Chinese discussions are welcome.

For an editing case, include:

- A small source sample and any synthetic input data.
- The selected element, intended operation, and affected scope.
- The expected source, instance-state, or binding change.
- Other elements and data that should remain unchanged.
- Any ambiguity, revision conflict, or unsupported expression involved.

Useful topics include component reuse, collection identity, data provenance,
code and canvas editing across revisions, and preview/publication consistency.
Distinguish an implementation you have tested from a proposed design.

Keep the English and Chinese descriptions aligned when changing shared concepts.
Use synthetic examples and code you have permission to contribute.
Include no merchant records, credentials, private runtime configuration, or internal logs.

Contributions are made under the repository's MIT license.
